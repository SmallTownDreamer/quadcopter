# FastDepth 单目深度估计：下一阶段计划

参考：[Seeed reCamera FastDepth INT8 教程](https://wiki.seeedstudio.com/cn/recamera_deploy_monocular_depth/)。本文件记录开发计划，不表示已部署或复现教程性能。

## 开发系统

用户已有 Ubuntu，建议使用 Ubuntu + Docker 进行模型转换和 C/C++ 交叉编译。Windows 也可以通过 WSL2 + Docker 开发，但非必要。板卡保留现有匹配的 Buildroot 系统，不换 Ubuntu、不刷 reCamera 固件。电脑系统不决定板卡最终推理速度。

## 移植注意

reCamera 和 LicheeRV Nano 同为 SG2002，但系统服务、SDK、运行库和采集应用不同。教程中的 reCamera 用户、IP、supervisor 服务及编译产物不能直接照搬。

先核对 PCB 70405/70415、固件与 TPU 库版本。若为 70405 内测硬件，核对官方 0.5T 运行限制，不盲目配置 1T：[Sipeed 板卡资料](https://wiki.sipeed.com/hardware/en/lichee/RV_Nano/1_intro)。

## 实施顺序

1. 在 Docker 中准备教程固定工具版本：`sophgo/tpuc_dev:v3.4` 与 `tpu_mlir[onnx]==1.28.1`；按教程补 psutil 和 CPU 版 torch。是否仍可安装需实际检查。
2. 获取 FastDepth 权重，补齐导出脚本，产生并简化固定 `1×3×224×224` ONNX。
3. 用一张图片确认浮点输出和 RGB、resize、/255、CHW 预处理一致。
4. 采集约 500 张代表性图片标定 INT8；避免大量连续近重复帧。
5. 编译目标 `cv181x`，运行教程两个数值验证关卡；成功打印不等于数值正确。
6. 使用匹配本板固件的 SDK 编译完整 cviruntime 推理程序；教程 API 片段不是完整运行器。
7. 先做输入文件 → 板端 TPU → 输出深度图的离线单张验证。
8. 再统一摄像头/VPSS，为算法和监控分出不同输入输出，避免另一程序争抢 sample_venc 的资源。
9. 测量采集、预处理、推理、后处理和监控并发的完整性能。

FastDepth 输出相对深度，不直接代表米；室外和夜间效果受训练域影响。教程约 54fps 属模型推理基准，不是本项目完整链路承诺。

大模型、数据集、标定图片、权重和转换中间产物不放 Git；未来补充来源、版本、校验值及复现命令。
